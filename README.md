# Προσβάσιμες διαφάνειες για το μάθημα Λογική Σχεδίαση του ΕΚΠΑ

Οι παρούσες διαφάνειες έχουν μετατραπεί σε προσβάσιμη μορφή με σκοπό το να είναι ευανάγνωστες από τυφλούς φοιτητές, κάτι που παρεμποδίζεται από μερικά προβλήματα που παρουσιάζουν οι διαφάνειες σε μορφή PDF που παρέχονται κανονικά από το E-Class του μαθήματος. Εάν σκοπεύετε να μελετήσετε κάνοντας χρήση τους, βεβαιωθείτε ότι έχετε διαβάσει εξολοκλήρου την εισαγωγή αυτή.

Στην προσβάσιμη μορφή των διαφανειών, οι εικόνες τους έχουν αντικατασταθεί από κειμενικές περιγρα΄φες. Επίσης, έχουν συμπεριληφθεί μαθηματικά που μπορούν να διαβαστούν από αναγνώστες οθόνης (αν είστε χρήστης NVDA διαβάστε την ενότητα MathCAT παρακάτω). Τα μαθηματικά στις PDF διαφάνειες δεν δίνουν στους αναγνώστες οθόνης αρκετές πληροφορίες. Το γεγονός αυτό έχει ως αποτέλεσμα πολλά μέρη των μαθηματικών εκφράσεων, όπως εκθέτες και δείκτες, να διαβάζονται σαν απλοί αριθμοί.
